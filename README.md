精卫（JingWei）—— **个人数字资产库**，是存储和管理个人的数字化资产的数据存储和管理库，
并且所有数据均以**结构化**形式存储。

用户应用程序均在该库之上构建，其只能直接读取或查询存储在该库中的结构化数据，
而不能访问网络或读写文件，从而杜绝应用程序的恶意行为。

用户数据将不再受制于平台，应用程序也不再面对**数据冷启动**的问题，可直接访问到用户积累的全部数据，
从而真正实现「**数字资产为用户的私有财产**」的目标。
